Second-hand servers often still have an old OS on another drive. Redfish Hdd alone cannot pick one RAID volume over that old disk — and Hdd Continuous actively fights BootOrder on multi-disk HPE boxes. After imaging, Copper runs efibootmgr on the live OS to create a UEFI entry on this disk’s ESP and put it first in BootOrder, then clears the BMC override. Needs efibootmgr on the live image.

3. cloud-init (cidata)

Written into the installed root filesystem as NoCloud seed plus a netplan drop-in. Batch mode expands hostname/address patterns per host and resolves each host’s MAC (never reuse one NIC’s MAC for the whole batch). Per-server provisioned_* inventory fields win over these form values when set.

  • /var/lib/cloud/seed/nocloud/user-data — users / hostname
  • /var/lib/cloud/seed/nocloud/meta-data — instance-id
  • /var/lib/cloud/seed/nocloud/network-config — netplan v2 (cloud-init NoCloud)
  • /etc/netplan/99-copper.yaml — same network config (hard fallback; overrides stock cloud-init netplan)

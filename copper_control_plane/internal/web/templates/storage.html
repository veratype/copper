Example on one disk: 100GB then all remaining → two VDs/LDs. Empty last row = rest of free space. MegaRAID keeps one RAID level for the whole group; Smart Array may differ per LD later via Slice.

On MegaRAID, UGood drives are held by the controller and invisible to Linux; only JBOD (or a VD) produces /dev/sdX. Use Expose as JBOD for Ceph/ZFS hosts, or Create for a RAID volume (Create plans UGood first). Plan several sized volumes in the list above to split one disk (or drive set) into multiple VDs/LDs in one Create. Use Slice later to carve more from free space.

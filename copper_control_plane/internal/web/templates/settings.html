Settings

Session, batch runtime, live-OS SSH, and data-plane media. Stored in the control-plane database.

Back to servers

Web session

How long you stay signed in. The cookie is renewed on every request while you use the UI (Jobs polling, Deploy, etc.), so an active admin is not kicked mid-work. Default 12 hours; max 720 (30 days).

Live OS SSH

Shared credentials for the data-plane live image. Control plane SSHs to each server’s Data DHCP IP (from inventory NIC MACs + leases) to run ssacli / storcli and OS provision. User must be a sudoer. Leave password blank to keep the stored value.

Data media (cloud images)

HTTP file server on the data plane (like copper_bmc media on OOB). Drop Ubuntu cloud images into the folder; live hosts pull them when provisioning. Prefer a concrete Bind IP the servers can reach (or rely on the Data DHCP NIC for Base URL).

Batch executors

How many servers to process at once (Probe, Inventory, Mount, Detect RAID, and Deploy OS writes). Default 3; hard max 16. Raising this for Deploy can saturate the data-media NIC while hosts download the cloud image.

Agent watch

How often the control plane checks copper_bmc health and auto-repushes OOB DHCP if the agent is up but DHCP is not running. Default 60 seconds; range 5–3600. Takes effect on the next tick (no restart).

Per-action timeouts

Seconds for each server call in a batch. Detect talks SSH + RAID CLIs on the live OS. Mount & boot also waits for Data DHCP + SSH after reboot to claim live-OS NIC MACs into inventory (for NICs Redfish omitted). Provision covers cloud-image download + write.

Reset form

Danger zone — purge all

Wipe inventory and DHCP state: every server, label, job, snapshot, Data DHCP leases/bindings, saved OOB + Data DHCP policies, and poll-mode agent command queue / heartbeat cache. Also stops Data DHCP here and, when copper_bmc is reachable with the DHCP role on, disables OOB DHCP and clears its leases (works in listen and poll agent modes). Does not remove session timeout, live-OS SSH, data media, or batch executor settings.
